# main/ 規則

最外層：把各層組裝起來。入口可以是 `__main__.py`、命令列工具，或專案原本的進入點。

- **MAIN-1【必須】** 只做組裝：透過 storage 讀取設定與資料、建立 adapter、呼叫 flow、透過 storage 儲存結果。
- **MAIN-2【必須】** 不寫業務邏輯或資料轉換。依「設定值」選擇要用哪個 adapter 或 flow 可以；依「資料內容」做判斷或計算，就移到 steps 或 flows。
- **MAIN-3【必須】** 目前時間、亂數 seed 在這裡產生；設定與環境變數透過 storage 讀取。兩者都用參數往下傳。
- **MAIN-4【建議】** 一個入口只組裝一條主流程；有多條流程時，每一條各寫一個函式，依任務命名（`train`、`evaluate`、`predict`）。
